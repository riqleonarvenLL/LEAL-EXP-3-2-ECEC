# 🚗 Experiment 3: Python Data Analysis (Pandas)

This repository contains my solution for **ECE 2112: Advanced Computer Programming and Algorithms – Experiment 3**.  
The task focuses on **loading, slicing, indexing, and filtering data** using the `pandas` library in Python.

---

## 📘 Learning Outcomes
- Load a CSV dataset into a Pandas DataFrame  
- Perform positional and label-based indexing  
- Apply Boolean conditions for filtering  
- Extract subsets of data without modifying the source
